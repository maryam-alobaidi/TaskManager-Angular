# 📝 Angular Task Manager
A modern, reactive task management application built with **Angular 19** and **Signals**.

### 🚀 Features:
- **Local Storage:** Your tasks are saved locally in the browser.
- **Reactive UI:** Instant updates using Angular Signals.
- **Filtering:** View All, Active, or Completed tasks.
- **Responsive Design:** Beautiful and clean UI.

### 🛠️ Tech Stack:
- Angular (Core, Signals, Router)
- CSS3 (Flexbox, Custom Animations)
- TypeScript
